1분 설치

차단은 인스타그램 안에서 동작합니다

iPhone에서는 Userscripts(무료) 앱이 가장 간단합니다. 앱이 사파리 확장으로 인스타그램 페이지에 이 스크립트를 넣어 줍니다.

  1. 1
    Userscripts 설치

    App Store에서 Userscripts를 받고, 설정 › 앱 › Safari › 확장 프로그램에서 켠 뒤 instagram.com 접근을 허용하세요.

  2. 2
    스크립트 넣기

    아래 파일로 저장을 누르고, 파일 앱에서 Userscripts 폴더로 옮기면 목록에 나타납니다. (앱에 편집기가 있으면 복사한 내용을 붙여넣어도 됩니다.)

  3. 3
    인스타그램 열기

    사파리에서 instagram.com을 열면 하단 바에서 릴스가 사라집니다. 오른쪽 아래 SL 버튼이 설정 패널입니다.

이 앱을 홈 화면에 추가하면 주소창 없는 앱처럼 열립니다. 사파리 공유 버튼 › 홈 화면에 추가.
홈 화면 설치는 https 주소(또는 localhost)에서만 동작합니다. README의 “배포”를 참고하세요.

Orion 브라우저는 유저스크립트를 기본 지원합니다.

  1. 1
    설정 열기

    Orion › 설정 › 확장 프로그램 › Userscripts.

  2. 2
    붙여넣기

    유저스크립트 복사 후 + 버튼에 붙여넣고 저장하세요.

  3. 3
    적용 확인

    instagram.com을 열고 새로고침. 릴스 탭이 사라졌는지 확인하세요.

파일 내려받기

Chrome · Edge · Firefox · 사파리(맥) 모두 같은 방법입니다.

  1. 1
    Tampermonkey 설치

    확장 프로그램 스토어에서 Tampermonkey 또는 Violentmonkey를 설치하세요.

  2. 2
    새 스크립트

    대시보드 아이콘 › 새 스크립트 만들기 › 기본 내용을 지우고 복사한 코드를 붙여넣고 저장(Ctrl+S).

  3. 3
    인스타그램 새로고침

    주소창 옆 확장 아이콘에 숫자 1이 보이면 동작 중입니다.

파일 내려받기

iOS 단축어 앱과 묶으면 인스타그램 앱에서 링크를 받아 안전 모드로 열거나, 홈 화면에 전용 실행 아이콘을 만들 수 있습니다.

  1. 1
    릴스 없는 인스타 열기

    단축어 앱 › 새 단축어 › URL 열기 동작을 추가하고 아래 실행 URL 복사로 넣은 주소를 붙여넣으세요. 이름을 “릴스 없는 인스타”로 저장하고 홈 화면에 추가하면 끝.

  2. 2
    공유 시트로 받은 릴스 열기

    새 단축어 › 단축어 입력 받기(URL) › 텍스트의 … 단계로 /reel/ 주소를 그대로 URL 열기에 넘깁니다. 인스타그램 앱의 공유 › 단축어로 실행하면 사파리가 안전 모드로 한 편만 엽니다.

  3. 3
    자동화(선택)

    단축어 › 자동화 › 앱 열림에서 인스타그램을 고르고 “릴스 없는 인스타”를 실행하게 하면, 앱을 열 때마다 사파리로 넘어갑니다. (자동화는 iOS가 확인을 요구할 수 있습니다.)

단축어는 “어디로 열지”만 정합니다. 릴스를 실제로 걷어내는 일은 설치된 유저스크립트가 합니다.

설치 없이 한 번씩 실행하는 방법입니다. 새로고침하면 풀리므로 매번 눌러야 합니다.

  1. 1
    코드 복사

    아래 버튼으로 javascript: 코드를 복사합니다.

  2. 2
    북마크 만들기

    아무 페이지나 북마크한 뒤, 북마크를 편집해 주소(URL) 칸을 복사한 코드로 바꾸고 이름을 SocialLite로 저장하세요.

  3. 3
    인스타그램에서 실행

    instagram.com을 연 상태에서 그 북마크를 선택하면 바로 적용됩니다.
